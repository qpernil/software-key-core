# Published cryptographic test vectors

The shared cryptographic implementation is checked against committed expected
outputs from NIST ACVP/CAVP, Wycheproof and the relevant RFCs/drafts. These tests
run offline as ordinary unit tests. `cargo test --locked kat_` runs the imported
corpora; `cargo test --locked --all-features` includes them and the existing
standard vectors. Both shared-core CI and pkcs11rs CI run these KATs.

## Scope and interpretation

Expected outputs are taken from the publishers, not generated by the code under
test. Fixture source versions, source hashes, selection rules and licenses are
recorded in the source directories. JSON is compacted and compressed with a zero
gzip timestamp; expected cryptographic outputs and result classifications are
unchanged. A Wycheproof `acceptable` case may be rejected; an accepted key-agreement
case must still produce the published shared secret.

ML-DSA retains the external signature interface, all exposed prehash algorithms,
and all three parameter sets. Internal/external-mu interfaces and SHA-512/224
and SHA-512/256 are outside the supported public API. Signature generation uses
trusted expanded fixture keys and supplied randomizers through the crypto
library's internal signing entry point; verification uses the production
shared-core functions and HashML-DSA encoding/hash construction is shared with
production. This does not test operating-system RNG health.

ECDSA uses the production P1363 prehash verifier for all eight supported
Weierstrass curves. SHAKE-ECDSA datasets are excluded because the provider does
not expose composite SHAKE-ECDSA mechanisms. ECDH fixtures retain only canonical
SPKI with the declared curve algorithm and add its extracted SEC1 point; the
production shared-core API accepts SEC1 rather than ASN.1. ASN.1 container and
explicit-curve-parameter validation belong to callers and are not claimed by
these raw ECDH tests. The selection counts are in the Wycheproof manifest.

SHAKE ShortMsg/LongMsg answers specify 16/32 bytes; these check the prefix of
the 32/64-byte HashML-DSA output. VariableOut answers of exactly 32/64 bytes
check the complete output. SHA-512/224, SHA-512/256, bit-oriented hashing,
Monte Carlo repetitions, interleaved TDES and unimplemented cipher modes are
excluded. Test coverage is algorithm regression evidence, not FIPS module
certification or CAVP validation.
