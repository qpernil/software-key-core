These are pinned NIST ACVP-Server FIPS 203/204 vectors from commit
`975de31eb83d87039ec88934fdc47d8c312b892d`, under `gen-val/json-files/`.
The source folders are `ML-DSA-{keyGen,sigGen,sigVer}-FIPS204` and
`ML-KEM-{keyGen,encapDecap}-FIPS203`, each using `internalProjection.json`.

All key-generation and KEM cases are retained. ML-DSA signing and verification
retain the external signature interface and all supported hash algorithms.
Internal/external-mu APIs and SHA-512/224 and SHA-512/256 prehashes are excluded
because the public shared-core interface does not implement them. Expected
keys, signatures, ciphertexts, secrets, and pass/fail results come directly
from NIST; no expected cryptographic output is generated by this project.
The unused private key is removed from signature-verification cases.
JSON whitespace is removed and gzip timestamps are zero for reproducibility.
Tests run offline; fixture loading does not perform network requests.

## Classical NIST CAVP fixtures

The archives linked by NIST's [block-cipher](https://csrc.nist.gov/projects/cryptographic-algorithm-validation-program/block-ciphers)
and [secure-hashing](https://csrc.nist.gov/projects/cryptographic-algorithm-validation-program/secure-hashing)
validation pages supply the classical vectors. `classic-manifest.json` records
archive SHA-256, retained source `.rsp` names and case counts. The source fields
are preserved in compact JSON. All supported ECB/CBC TDES KAT files and byte
SHA-1/224/256/384/512, SHA3-224/256/384/512 and SHAKE ShortMsg/LongMsg files
are retained. SHAKE VariableOut retains the HashML-DSA 32/64-byte output sizes.
Unsupported bit-oriented modes, truncated SHA-512 variants, interleaved TDES
and Monte Carlo repetitions are excluded.
